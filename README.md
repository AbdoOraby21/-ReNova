# ReNova — Complete React Demo Platform

منصة ذكية لبيع وشراء الخردة والمنتجات المعاد تدويرها.

## التشغيل المحلي

```bash
npm install
npm run dev
```

## ملاحظات هامة
- هذا التطبيق عبارة عن نسخة تجريبية (Demo) للعرض فقط.
- جميع البيانات تُحفظ محلياً في المتصفح (localStorage).
- لا يتطلب التطبيق أي قاعدة بيانات خارجية أو إعدادات Supabase.
- يدعم التطبيق الوضع الليلي (الافتراضي) والوضع الفاتح.
- التطبيق يدعم اللغة العربية بالكامل (RTL).
