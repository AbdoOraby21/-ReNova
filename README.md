# ReNova — Smart Recycling Marketplace

منصة ذكية لبيع وشراء الخردة والمنتجات المعاد تدويرها.

## التشغيل المحلي

```bash
npm install
npm run dev
```

## الحسابات والمصادقة

- التسجيل وتسجيل الدخول حقيقيان عبر Supabase Auth (مع تأكيد البريد الإلكتروني).
- حساب المشرف يُنشأ من Supabase Dashboard (Authentication → Users) بالبريد:
  `admin@renova.demo`
  ثم يُضاف إلى قائمة الإدارة في قاعدة البيانات (انظر `supabase/SETUP.md`).
- لا توجد حسابات عرض بكلمات مرور مضمّنة في الواجهة.

## البيانات

- المنتجات والأقسام وصور المنتجات: بيانات حقيقية في Supabase (10 منتجات و11 قسمًا أساسيًا).
- الطلبات وسجلات العرض الفارغة تعرض حالة صريحة: «لا توجد بيانات متاحة حاليًا» بدلًا من بيانات وهمية.

## الدعم

- البريد: `renovateam.support@gmail.com`

## ملاحظات هامة

- يتطلب التطبيق إعداد متغيرات Supabase في ملف `.env` (غير مُضمّن في المستودع).
- صلاحيات الكتابة (منتجات/أقسام/صور) محمية على مستوى قاعدة البيانات عبر RLS ولا يملكها إلا المشرف.
- يدعم التطبيق الوضع الليلي (الافتراضي) والوضع الفاتح.
- التطبيق يدعم اللغة العربية بالكامل (RTL).
